# Skill 归档 V1

整理日期为 2026-11-19。仓库包含 8 个 Skill 的文件，共 13,128 个 Skill 文件，同时提供本机盘点的 109 条 Skill 和版本记录。

| 路径 | 内容 |
| --- | --- |
| [SKILLS.md](SKILLS.md) | Skill 清单、版本、许可记录和获取方式 |
| [LICENSES.md](LICENSES.md) | 已收录 Skill 对应的许可文件 |
| [上传说明](GITHUB.md) | Windows 一键发布、GitHub Desktop 和 ZIP 上传步骤 |
| `.agents/skills/` | 可随此目录使用的 Skill 及配套文件 |
| `SHA256SUMS.txt` | 归档文件的 SHA-256 |

在 Codex 里打开此目录，用 `$Skill名称` 调用所需 Skill。需要用户级安装时，把 `.agents/skills/` 下的整个 Skill 子目录复制到 `~/.agents/skills/`。插件型 Skill 的安装入口见索引。PPT Master 的模板、图标和声音资源随目录保留，运行依赖按其 `SKILL.md` 配置。 [Codex Skill 文档](https://developers.openai.com/codex/skills)

每项 Skill 的许可按各目录所附文件执行。带有专有许可、仅有插件或 Skill 许可字段、缺少许可文件或包含本机路径的项目可在索引中按来源查找。 [GitHub 仓库许可说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)
